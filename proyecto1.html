Static Routing and ACLs (ITB Holding)

Network infrastructure configuration for ITB Holding. The project encompasses the interconnection of branches using static and floating routes, as well as securing the internal network using Access Control Lists (ACLs).

💡 Solved Technical Challenges

This scenario simulates a critical environment with redundancy and security. You can download the source file or expand the details.

📥 Download Project
  • 🔀
    Routing and Redundancy

    Configuration of static routes on R1, R2, and R3. A Floating Route was implemented via Subnet H to ensure connection if Subnet F fails.

  • 🌐
    Internet Access

    Configuration of a Default Route on router R1 towards the ISP, allowing web access for the entire company.

  • 🛡️
    Security (ACLs)

    Implementation of strict firewall policies:

    • ❌ Total blocking of host PCC2 (Subnet C).
    • 🔒 Subnet A only allows HTTP (80) and DNS (53) traffic.
    • 🚫 Subnet E has web browsing blocked.
