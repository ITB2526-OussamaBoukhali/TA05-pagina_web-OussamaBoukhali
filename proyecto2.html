Network Segmentation (VLANs) and DHCP

Design and implementation of a segmented corporate network architecture. The project logically separates departments using VLANs, manages traffic with Inter-VLAN routing, and automates IP address assignment.

💡 Solved Technical Challenges

Optimization of network security and performance through logical segmentation. Download the source file or expand the details below.

📥 Download Project
  • 🏢
    Logical Segmentation (VLANs)

    Creation of separate virtual networks to isolate traffic and improve security:

    • 🔹 VLAN 10: Sales Department.
    • 🔸 VLAN 20: Administration Department.
    • Implementation on floor switches (01_Planta1, 01_Planta3) and central switch (ITB1).
  • 🔀
    Inter-VLAN Routing

    Configuration of "Router-on-a-Stick" on the Central Router to allow controlled communication between VLANs and the shared server, using 802.1Q subinterfaces.

  • ⚙️
    Automation (DHCP Server)

    Deployment of DHCP service on the Cisco router for the Sales network. Exclusions were configured for the first 20 IPs (reserved for static) and dynamic assignment for new hosts.

🛠️ Technologies:

Cisco Packet Tracer VLANs (802.1Q) Inter-VLAN Routing DHCP Server Trunking & Native VLAN
